# Outputs - Iris Flower Classification

This folder contains the output visualizations and screenshots generated during the execution of the **Iris Flower Classification** task.

The outputs demonstrate the dataset exploration, data analysis, model performance, and prediction results obtained from the trained Machine Learning model.

## Output Visualizations

### 1. confusion_matrix.png
Displays the confusion matrix of the Random Forest classification model, showing the correct and incorrect predictions for each Iris species.

### 2. pairplot.png
Shows the pairwise relationships between the different Iris flower measurements and helps visualize the separation between the three Iris species.

### 3. species_distribution.png
Displays the distribution of the three Iris species in the dataset.
